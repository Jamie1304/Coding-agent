# Privacy modes

Maximum Privacy is local-only for sensitive tasks. Cloud fallback is disabled unless policy is changed and the user explicitly approves cloud use for the run.

The routing descriptor marks sensitive work, while model metadata distinguishes local from cloud execution. A cloud provider cannot become eligible merely because it is cheaper or faster.

Provider credentials stay in Windows Credential Manager and are accessed only by the daemon. SQLite, configuration export, logs, renderer responses, reports, and database backups contain references or masked status, never secret values.

Before enabling a cloud provider, review what repository text, prompts, attachments, and tool results its tasks may receive. Repository-writing work stays in the Codex approval/worktree workflow.
